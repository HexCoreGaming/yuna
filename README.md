# YUNA POCKET — V1.0.1

New website, built as a standalone static application. Upload all files/folders to the root of your GitHub Pages `yuna` repository; `index.html` is the entry point. Password 1: `YUNA-MOUTH`. Password 2: `LUNA-BUTT`.

**What is different:** This build does NOT draw Yuna with SVG primitives. It uses painted Yuna artwork cut into separately addressable head, torso, arms, chest, hips and leg layers, animated at distinct pivots on HTML Canvas. Includes a newly written minimal interface, drag-to-lean, breathing, joint poses, spring responses, expressions-as-dialogue, manual actions, automation and zoom.

**What it does not do:** This is a *cutout rig* built from pre-existing Yuna images, not a fully redrawn anime model and not a professional Live2D rig. The facial expression buttons change mood/dialogue but **do not yet redraw the face**. The artwork layers are imperfect and can leave overlaps or seams; complex 3D turns, full joint articulation, sexual animation, proper deforming cloth/skin, mouth shapes and organic facial expressions are not delivered. GitHub-hosted client-side password checks do **not** secure the files.

Sections [001]–[007] are numbered in `app.js`; structure and CSS are likewise labeled. No 3D residence, no previous SVG model, no Luna.

This is version V1.0.1 and it is displayed on the first login screen and main application. All content is local files; no third-party JavaScript/CDN needed. Art assets derived from the user's existing Yuna Pocket V1.1 files.
