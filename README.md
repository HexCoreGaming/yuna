# Yuna Residence V0.9 — Appearance Focused Update

This ZIP focuses **only on Yuna's appearance**.

What changed:
- Rebuilt Yuna as an **appearance-first 3D character** using the approved front / side / back artwork directly.
- Added **8 directional view cards** (front, front-right, right, back-right, back, back-left, left, front-left) so she reads better from more angles.
- Added subtle **face emphasis**, softer holographic glow, and cleaner silhouette presentation.
- Added **gentle hair motion** and preserved secondary-motion controls.

What did **not** change on purpose:
- No controller rewrite.
- No residence layout rewrite.
- No new gameplay systems.
- No claim that this is a fully hand-sculpted AAA character model.

Important limitation:
- This version should look closer to the approved image than the previous procedural-body versions, but it is still an **image-based 3D presentation**, not a professionally sculpted and rigged custom model.

Run locally the same way as before.
